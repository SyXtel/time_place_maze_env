# time_place_maze_env
A Gymnasium-based simulation environment of the Time-Place Maze* experiment for studying temporal and spatial learning in biologically inspired reinforcement learning agents. 

>*Amlashi, F. I., Ashkbari, A., Jahanshahi, M., Sohrabi, A., & Ahmadi-Noorbakhsh, S. (2026). The time-place maze: A novel behavioral apparatus for assessing integrated spatial-temporal processing in rats. PloS one, 21(2), >e0340114. https://doi.org/10.1371/journal.pone.0340114
